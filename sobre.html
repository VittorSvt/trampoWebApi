Sobre a Atividade

Esta página foi criada como uma demonstração prática dos conceitos de HTML5 semântico e de APIs Web.

O objetivo é mostrar que uma estrutura bem desenvolvida melhora a acessibilidade, a leitura por motores de busca e a organização do código.

Requisitos Cumpridos:

  • Estrutura semântica correta (<header>, <nav>, <main>, <section>, <footer>).
  • Navegação entre páginas configurada corretamente.
  • Implementação da Web Storage API para persistência de dados simples no cliente (o nome do usuário se mantém salvo mesmo ao atualizar a página inicial).
  • Implementação da Geolocation API para interação em tempo real com o hardware/sensores do usuário.
